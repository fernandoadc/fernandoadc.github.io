# Portfólio (GitHub Pages)

Site estático (HTML + CSS), sem build.

1. Crie o repositório `SEU-USUARIO.github.io` e suba estes arquivos na raiz.
2. Settings → Pages → Deploy from a branch → `main` / root.
3. Procure por `TODO` (`grep -r TODO .`) e troque e-mail e usuário do GitHub.
4. Coloque sua foto aqui só se quiser trocar o avatar do GitHub: use `assets/photo.jpg` em `index.html`.
5. Publicações: edite `publications.bib` (exporte do Mendeley em BibTeX). O BibBase lê o arquivo pela URL raw do GitHub.
   Para ler direto do Mendeley, gere o snippet em https://bibbase.org (opção Mendeley) e cole o `src` em `publications.html`.
   O Mendeley mudou a API em 2025, então pode ser preciso reautorizar o BibBase lá.
6. Confira `publications.bib`: páginas do artigo da Scientometrics e entradas sem link/DOI.
